How to use this tool

  • Upload all the DOC split files.
  • Click "Validate Files" to check date consistency.
  • View the validation results for each split file.
  • Any date mismatches will be shown under each file, row by row.
  • Click "Correct Dates" to fix the mismatches.
  • The corrected dates will then appear under each file, row by row.
  • Click "Download Corrected Files" to save the updated files.
  • You can also re-upload the corrected DOC split files if needed.
